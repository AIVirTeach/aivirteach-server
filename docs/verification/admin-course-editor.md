# 课程后台 A：实现与验证

本次只实现运营课程后台。V2 学员页面接线、4c 运营管理和迁移 B 留在后续范围。

## 设计

保留 Server Component 读取和 Server Action 写入。浏览器不直接持有运营令牌或调用 Nest。每个课时拥有自己的块列表、撤销历史和串行保存队列。保存响应只确认对应 revision，不覆盖当前内容。发版和丢弃草稿放在课程页；未保存表单阻止离开或发布。

两个独立设计检查比较了单课时状态和整课程协调器，均选择单课时状态。第三份独立检查确认这个选择，要求统一保护表单、上传、退出和浏览器返回。三份检查使用同一模型，不代表跨模型验证。

GET draft 增加 effectiveMeta，合并已发布课程元信息与草稿的部分修改；数据库中的 meta 仍保持部分修改语义。发版错误保留 problems 字符串，并新增可定位到模块、课时和块的 issues。创建测评在锁住草稿后进行，写入与审计同一事务。

## 运行本地检查

使用 Node、npm 和本地 PostgreSQL。数据库必须是 `127.0.0.1` 上专用的 `aivirteach_4b`，不得使用生产连接。

```sh
npm ci
DATABASE_URL=postgresql://aivirteach@127.0.0.1:55439/aivirteach_4b scripts/verify-admin-editor.sh
```

脚本执行迁移、测试、类型检查和构建。默认不启动浏览器。2026-10-22 用户要求暂不使用浏览器，因此浏览器验收暂停。

## 浏览器验收准备

以下步骤只在恢复浏览器验收后执行。需要三个本地服务：

- API：在 `apps/api` 目录运行 `node -r ts-node/register -r tsconfig-paths/register test/admin-editor-server.ts`，显式设置本地 DATABASE_URL、至少 32 字符的测试 JWT_SECRET 和 PORT=4400。
- admin：设置 `API_BASE_URL=http://127.0.0.1:4400/api/v1`、`NEXT_PUBLIC_CLIENT_ORIGIN=http://localhost:3301`，启动 3300 端口。macOS 沙箱可使用 `WATCHPACK_POLLING=true npm run dev -w admin -- --webpack --hostname 127.0.0.1 --port 3300`。
- client：使用真实 client checkout，设置 `NEXT_PUBLIC_ADMIN_ORIGIN=http://127.0.0.1:3300`，在 3301 端口启动。它提供已有 `/preview/lesson` 渲染器；无需修改 V2。

浏览器用例位于 `apps/admin/e2e/course-editor.spec.ts`。测试账号和密码仅存在于本地测试 harness。测试 harness 替换图片存储为内存，并通过 HTTP 返回真实上传字节；它没有接入生产入口。该测试不证明真实 Vercel Blob 上传、生产 CORS 或部署保护配置正确。

## PR #29 审查修复

普通表单原先在保存响应返回后立即解锁，服务器刷新还未完成时的新输入会被表单重建覆盖。`MutationForm` 现在用 React transition 将刷新、清除未保存状态和成功提示一起提交；请求与刷新期间持续禁用表单和重复提交，并保留父级发布限制与离开页面保护。

新增回归使用实际 React Suspense 延迟刷新数据，没有 mock `useTransition`。修复前在输入框提前解锁的断言失败，修复后验证刷新期间保护、刷新完成后的解锁和后续编辑均通过。后台 22 个文件、84 项测试、TypeScript 与生产构建通过。本轮未重跑 API 和数据库测试，未启动浏览器；上表为此前完整实现的检查记录。
